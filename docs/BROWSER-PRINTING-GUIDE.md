# 🖨️ دليل الطباعة من المتصفح / Browser Printing Guide

**المشكلة:** الكاشير يستخدم المتصفح (تابلت/جوال) ولا يستطيع الطباعة على الطابعات المتصلة بالكمبيوتر الرئيسي

**التاريخ:** 2026-09-10

---

## 📊 فهم المشكلة

### السيناريو الحالي:

```
┌──────────────────────────────────────┐
│   كمبيوتر الخادم / Server PC        │
│   IP: 192.168.1.10                   │
│                                       │
│   ✅ NOKTA POS Server يعمل          │
│   ✅ Desktop App يعرف الطابعات      │
│   ✅ الطابعات متصلة هنا:            │
│      🖨️ USB Thermal Printer         │
│      🌐 Network Printer              │
└──────────────────────────────────────┘
              │
              │ WiFi LAN
              │
┌──────────────────────────────────────┐
│   جهاز الكاشير / Cashier Device    │
│   (Tablet / Phone / Laptop)          │
│                                       │
│   📱 Chrome Browser                  │
│   🌐 http://192.168.1.10:3000       │
│   ❌ لا يرى الطابعات مباشرة          │
└──────────────────────────────────────┘
```

### لماذا المتصفح لا يرى الطابعات؟

1. **قيد أمني:** المتصفحات لا تسمح للمواقع بالوصول المباشر لأجهزة USB/COM/Bluetooth
2. **معزول:** كل جهاز له طابعاته الخاصة المحلية فقط
3. **الشبكة:** المتصفح لا يستطيع إرسال أوامر RAW للطابعات الشبكية مباشرة

**هذا ليس خطأ في NOKTA POS - هذا قيد في جميع المتصفحات لأسباب أمنية!**

## ✅ الحل: الطباعة عبر الخادم (Server-Side Printing)

### كيف يعمل:

```
┌─────────────────┐           ┌─────────────────┐
│  Cashier Device │           │   Server PC     │
│    (Browser)    │           │  (With Printers)│
└────────┬────────┘           └────────┬────────┘
         │                             │
         │ 1. إتمام الطلب والدفع       │
         ├────────────────────────────>│
         │   POST /api/orders          │
         │   {items, total, ...}       │
         │                             │──> 💾 حفظ
         │                             │
         │ 2. طلب الطباعة من الخادم    │
         ├────────────────────────────>│
         │ POST /api/print/invoice/123 │
         │                             │
         │                             │──> 🖨️ يطبع!
         │                             │    (على الطابعة
         │                             │     المحلية)
         │                             │
         │ 3. تأكيد الطباعة            │
         │<────────────────────────────┤
         │    {success: true}          │
         ✓                             ✓
```

**الفائدة:**
- ✅ المتصفح لا يحتاج الوصول للطابعة مباشرة
- ✅ الخادم يطبع على الطابعة المحلية المتصلة به
- ✅ يعمل من أي جهاز (تابلت/جوال/كمبيوتر)

## 🔧 خطوات الإعداد الكاملة

### **المرحلة 1: إعداد كمبيوتر الخادم (Server)**

#### 1. تثبيت الطابعة في Windows:

```powershell
# خطوات التثبيت:
```

1. افتح **Settings** (⚙️)
2. اذهب إلى **Devices** → **Printers & scanners**
3. اضغط **Add a printer or scanner**
4. انتظر حتى تظهر الطابعة أو اختر **"The printer that I want isn't listed"**

**للطابعات USB:**
- Windows يكتشفها تلقائياً عند التوصيل
- تأكد من تثبيت التعريف (Driver) إذا لزم الأمر

**للطابعات الشبكية (Network):**
- اختر "Add a printer using a TCP/IP address"
- أدخل IP Address (مثل: `192.168.1.100`)
- Port: `9100` (للطابعات الحرارية)

5. **مهم جداً:** اطبع صفحة تجريبية من Windows:
   - Properties → Print Test Page
   - يجب أن تطبع بنجاح!

---

#### 2. إعداد الطابعة في NOKTA POS Desktop:

```powershell
# على كمبيوتر الخادم، شغّل Desktop App:
cd C:\Users\User\OneDrive\Desktop\test\pos-web
pnpm run desktop
```

**خطوات التكوين:**

1. سجّل الدخول كـ **مدير** (Admin)

2. اذهب إلى: **الإدارة** 👤 → **الإعدادات** ⚙️

3. انتقل لأسفل الصفحة لقسم **"إدارة والتعرف التلقائي على الطابعات"**

4. اضغط زر **"🔍 فحص واكتشاف"**
   - انتظر 3-5 ثوانٍ
   - يجب أن تظهر رسالة: "✅ تم العثور على X طابعة من النظام"
   - تظهر جميع الطابعات المثبتة في Windows

5. اضغط **"➕ إضافة طابعة"**

6. املأ النموذج:
   - **الاسم / القسم:** `طابعة الكاشير` (أو أي اسم واضح)
   - **اختر الطابعة:** اختر الطابعة من القائمة المنسدلة
     - يجب أن ترى الطابعات مع أيقونات:
     - 🖥️ للطابعات المثبتة في Windows
     - ⭐ للطابعة الافتراضية
   - **الأقسام المستلمة:** اترك فارغاً (لطباعة كل الطلبات)
   - **الوضع:**
     - ✓ **تلقائي** = يطبع فوراً عند حفظ أي طلب
     - ☐ **يدوي** = يطبع فقط عند الضغط على زر الطباعة

7. اضغط **"حفظ"**

8. اضغط **"💾 حفظ الإعدادات"** في أسفل الصفحة

9. **اختبار مهم جداً:**
   - في جدول الطابعات، ابحث عن الطابعة التي أضفتها
   - اضغط زر **🖨️** (الطباعة التجريبية)
   - يجب أن تطبع فاتورة تجريبية!
   - إذا لم تطبع، راجع الخطوات السابقة

---

### **المرحلة 2: إعداد إعدادات قاعدة البيانات**

الآن تحتاج لحفظ اسم/معرف الطابعة في قاعدة البيانات:

#### الطريقة 1: من واجهة الإعدادات (موصى به)

1. في نفس صفحة **الإعدادات** → **قسم الطابعات**
2. الطابعة التي أضفتها يجب أن تحتوي على:
   - `device`: معرف الطابعة (JSON)
3. انسخ هذا المعرف لاستخدامه في الخطوة التالية

#### الطريقة 2: إعداد يدوي في الإعدادات العامة

في نفس صفحة الإعدادات، ابحث عن قسم **"الإعدادات المتقدمة"** أو أضف حقل:

```javascript
// في قاعدة البيانات - جدول settings
// مفتاح: printer_cashier
// القيمة: {"type":"system","name":"اسم_الطابعة_في_Windows"}
```

أو يدوياً من Desktop App:
1. افتح Console (F12)
2. شغّل:
```javascript
await api('/api/settings', 'PUT', {
  printer_cashier: JSON.stringify({
    type: 'system',
    name: 'POS-80'  // ← استبدل باسم طابعتك
  })
});
```

---

### **المرحلة 3: اختبار من المتصفح**

الآن جرّب من جهاز كاشير (تابلت/جوال):

1. افتح المتصفح (Chrome موصى به)
2. اذهب إلى: `http://192.168.1.10:3000` (استبدل بـ IP الخادم)
3. سجّل الدخول كموظف كاشير
4. أنشئ طلب تجريبي:
   - أضف أصناف
   - اختر طريقة دفع
   - اضغط **"حفظ الطلب"** أو **"إتمام الدفع"**

**النتيجة المتوقعة:**
- ✅ يحفظ الطلب بنجاح
- ✅ ترى رسالة: "تم إرسال الفاتورة للطابعة (الكاشير)"
- ✅ **الطابعة المتصلة بالخادم تطبع الفاتورة!**

إذا لم تطبع:
1. تحقق من Console (F12 في المتصفح)
2. ابحث عن أخطاء `POST /api/print/invoice/...`
3. راجع الخطوات السابقة

## 🔍 استكشاف الأخطاء / Troubleshooting

### المشكلة 1: "لم يتم إعداد طابعة الكاشير"

**السبب:** الإعداد `printer_cashier` غير موجود في قاعدة البيانات

**الحل:**
1. افتح Desktop App على الخادم
2. اذهب للإعدادات → الطابعات
3. أضف طابعة كما في الخطوات أعلاه
4. احفظ الإعدادات

---

### المشكلة 2: الطلب يحفظ لكن لا يطبع

**الأسباب المحتملة:**

**أ. الطابعة غير متصلة:**
- تحقق من أن الطابعة مشغّلة
- تحقق من وجود ورق
- جرّب طباعة تجريبية من Windows

**ب. مشكلة في الكود:**
- افتح Console في المتصفح (F12)
- ابحث عن خطأ `POST /api/print/invoice/:id`
- أرسل رسالة الخطأ للدعم

**ج. إعدادات خاطئة:**
- تأكد من `printer_cashier` مضبوط صح
- جرّب الطباعة التجريبية من صفحة الإعدادات (زر 🖨️)

---

### المشكلة 3: يطبع من Desktop لكن لا يطبع من المتصفح

**هذا يعني:**
- ✅ الطابعة تعمل
- ✅ الإعدادات صحيحة
- ❌ المتصفح لا يستدعي API بشكل صحيح

**الحل:**
1. افتح Console في المتصفح (F12)
2. بعد حفظ طلب، راقب Network tab
3. يجب أن ترى: `POST /api/print/invoice/123`
4. إذا لم تراه، المشكلة في كود الواجهة الأمامية
5. راجع `public/js/features/orders/order-receipt-printing.js`

---

### المشكلة 4: يطبع لكن بتنسيق خاطئ

**الأسباب:**
- نوع الطابعة خاطئ (Inkjet بدلاً من Thermal)
- حجم الورق خاطئ (A4 بدلاً من 80mm)

**الحل:**
- تأكد من اختيار طابعة حرارية (Thermal) 80mm
- في `src/services/print.service.js`، الكود مُعد لطابعات حرارية فقط
- إذا كنت تستخدم طابعة عادية، ستحتاج لتعديل الكود

## 📋 الخلاصة والتوصيات

### ✅ ما يعمل حالياً:

| الميزة | Desktop App | Browser |
|--------|-------------|---------|
| التعرف على الطابعات | ✅ تلقائي | ❌ لا (عبر Server) |
| الطباعة المباشرة | ✅ | ❌ لا (عبر Server) |
| الطباعة عبر API | ✅ | ✅ نعم! |
| إعداد الطابعات | ✅ | ❌ لا (من Desktop فقط) |

### 📌 التوصيات:

#### لإعداد مطعم جديد:
1. ✅ ثبّت كمبيوتر خادم واحد مع الطابعات
2. ✅ استخدم Desktop App على الخادم للإعداد
3. ✅ استخدم المتصفح على جميع أجهزة الكاشير
4. ✅ الطباعة ستتم عبر الخادم تلقائياً

#### للاستخدام اليومي:
- 🖥️ **كمبيوتر الخادم:** يشتغل 24/7، يشغّل Desktop App أو الخادم فقط
- 📱 **أجهزة الكاشير:** تابلت/جوال تفتح المتصفح
- 🖨️ **الطابعات:** متصلة بالخادم فقط
- 📡 **الشبكة:** LAN واحد يربط الكل

#### للتوسع المستقبلي:
- إذا أردت طابعة منفصلة لكل كاشير، تحتاج:
  - تشغيل NOKTA Print Service على كل جهاز كاشير
  - أو استخدام طابعات شبكية (Network) مع IP ثابت

## 🎯 الأسئلة الشائعة

### س: هل يمكن طباعة من التابلت مباشرة؟
**ج:** لا، المتصفحات لا تدعم الوصول المباشر للطابعات USB. يجب الطباعة عبر الخادم كما هو موضح في هذا الدليل.

### س: هل يعمل مع iPad/iPhone؟
**ج:** نعم! Safari يدعم الطباعة عبر API. اتبع نفس الخطوات.

### س: ماذا لو كان الخادم مطفي؟
**ج:** لن تعمل الطباعة. الخادم يجب أن يكون يعمل دائماً أثناء ساعات العمل.

### س: هل يمكن استخدام طابعتين منفصلتين (كاشير + مطبخ)?
**ج:** نعم! أضف طابعتين في الإعدادات:
- طابعة 1: اسم "الكاشير" - الأقسام: فارغ
- طابعة 2: اسم "المطبخ" - الأقسام: أطباق رئيسية، مقبلات، إلخ

### س: الطباعة بطيئة، كيف أسرّعها؟
**ج:** 
- استخدم طابعة USB بدلاً من Network (أسرع)
- تأكد من سرعة الشبكة (WiFi قوي)
- قلل حجم الفاتورة (أقل أصناف = أسرع)
